# Proof scope

This repository contains validation artifacts and benchmark results.

It does not claim to solve open Ramsey numbers.

For official catalogue files, the public certificate engine checks:

- graph count
- Ramsey property
- duplicate graph6 lines
- edge statistics
- degree-sequence statistics
- SHA256 hashes

For R(5,5), the known 656-reference graph set is validated and used as a comparison set. Completeness is not claimed.
