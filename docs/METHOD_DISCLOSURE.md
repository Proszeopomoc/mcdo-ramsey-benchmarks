# Method disclosure policy

The MDO/MCDO Ramsey solver used to generate benchmark results is closed-source in this release.

Public:

- result tables
- validation summaries
- timing information
- hardware metadata
- SHA256 hashes
- public certificate summaries
- proof-scope boundaries

Not public:

- solver implementation
- internal implementation details
- internal implementation details
- internal implementation details
- private search strategy
- internal MDO/MCDO structure
- private acceleration mechanisms
